# Contributing to ClaudeReview Backend

Thank you for contributing to ClaudeReview Backend!
docs: add CONTRIBUTING.md for Java Spring Boot project## Setup

```bash
git clone https://github.com/Manugupranay/claudereview-backend.git
cd claudereview-backend
./mvnw spring-boot:run
```

## Requirements
- Java 21+
- - Maven 3.8+
  - - Claude API key
   
    - ## PR Guidelines
    - - Branch from `main`
      - - Follow Conventional Commits
        - - Add tests for new features
          - - Run `./mvnw test` before submitting
           
            - ## Code Style
            - - Follow Google Java Style Guide
              - - Use meaningful variable names
                - - Add Javadoc for public methods
